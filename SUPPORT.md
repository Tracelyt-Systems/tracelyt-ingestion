# Support Guide

Welcome to the Tracelyt Ingestion community. This document outlines where and how to obtain help with the project.

## Project Status

Tracelyt Ingestion is an open-source infrastructure project currently in the **foundation stage**. We do not provide enterprise SLAs, commercial warranties, or 24/7 support guarantees. Support is provided on a best-effort basis by maintainers and community contributors.

## Where to Get Help

### 1. Documentation
Please review the documentation available in the repository before opening issues:
- [Root README.md](README.md): Architecture overview, prerequisites, setup, and running instructions.
- [docs/architecture/](docs/architecture/): System boundaries and architectural decisions.
- [docs/development/](docs/development/): Local setup, testing guide, and code style.
- [docs/operations/](docs/operations/): Configuration reference and health probe operational guidance.
- [docs/security/](docs/security/): Threat model, data handling guidelines, and secure development practices.

### 2. GitHub Discussions
For general questions, architectural inquiries, or community discussions, use GitHub Discussions on this repository if enabled.

### 3. GitHub Issues
If you have identified a concrete defect or bug:
- Search existing open and closed issues first.
- If not found, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
- For feature proposals, submit a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml).

### 4. Security Concerns
For security-related issues, please follow the responsible disclosure process detailed in [SECURITY.md](SECURITY.md).
